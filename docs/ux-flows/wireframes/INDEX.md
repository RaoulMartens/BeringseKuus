# Wireframe-inventaris — MVP-pilot

Klikbaar prototype. Open [welkom.html](welkom.html) in een browser en navigeer
zonder JavaScript verder — alle overgangen zijn gewone links.

Desktop, 1200px canvas, navigatie bovenin (`.wf-topnav`). Geen tab bar. Alle schermen hebben
daarnaast een mobiele weergave (onder 700px).

De eindverantwoordelijke heeft een * achter de rolnaam, net als de andere velden die verplicht zijn om te publiceren. Wie niet beschikbaar is, verschijnt alleen als je op die naam zoekt.
