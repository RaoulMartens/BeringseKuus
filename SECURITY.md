# Beveiliging

*English: please report security issues privately via the **Security** tab → **Report a vulnerability**, not in
a public issue. Reports in English are welcome.*

## Een lek melden

Meld een beveiligingsprobleem **niet** in een openbaar issue of een pull request. Gebruik de privé melding van
GitHub: tabblad **Security** → **Report a vulnerability**. Alleen de beheerders van deze repository zien je
melding.

Zet erin: wat het probleem is, waar het zit (bestand, pagina of aanroep), hoe je het kunt nabootsen, en wat
iemand ermee zou kunnen doen.

## Wat eronder valt

- De code in deze repository.
- De app die uit deze code wordt gebouwd, zodra die in gebruik is.

Niet: problemen bij Supabase, Cloudflare, Resend of GitHub zelf (meld die bij die partij), aanvallen die alleen
werken door de site plat te leggen, en misleiding van mensen (phishing, social engineering).

## Wat je kunt verwachten

Dit is een vrijwilligersproject voor een vereniging. We streven ernaar een melding binnen 7 dagen te
bevestigen en houden je op de hoogte van wat we ermee doen. Er is geen beloning.

## Zelf onderzoeken

Doe dat op een eigen, lokale kopie (zie de README). Test niet tegen de echte app: daar staan gegevens van echte
leden. Bekijk, bewaar of deel geen persoonsgegevens, en stop zodra je ze tegenkomt.

## Ondersteunde versies

Alleen de laatste versie op `main` krijgt beveiligingsupdates.
